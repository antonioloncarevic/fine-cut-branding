Foundations

Four colors, clear roles.

Dark Blue carries the brand. Electric Blue is the accent that pulls the eye. Off White and Beige are the light grounds.

Usage ratio per layout

60 / 25 / 10 / 5. Dark Blue dominates, Off White carries text and light surfaces, Beige warms things up, Electric Blue stays rare so it keeps its punch. On light-first layouts, swap the first two.

Foundations

Opacity scales for every tint.

Seven fixed steps per color. Use these instead of picking random transparency, so tints stay consistent across files. Click a step to copy its rgba value.

Steps: 100 / 80 / 64 / 48 / 32 / 16 / 8. 80 and 64 for secondary text, 48 and 32 for borders and disabled states, 16 and 8 for background tints and hover fills.

Foundations

Which text goes on which ground.

Contrast is calculated live with the WCAG formula. Green means safe for any text size, yellow means headlines only, red means decoration only.

Watch this one. Electric Blue on Dark Blue fails for text at any size. On dark grounds, use Electric as a fill (buttons, tags, stat cards) with Off White text on top, and use the derived soft tint #94A3F5 when you need blue-ish text.

Reference

The rules that keep it consistent.

Do

  • Keep Electric Blue to roughly 5% of any layout, so it always reads as the accent.
  • Use one serif accent per headline, one to three words long.
  • Use Ivy Presto only at 40px and above, where its contrast shows.
  • Pull tints from the seven opacity steps, never eyeball a new one.
  • Put Off White text on Electric fills when they sit on Dark Blue.

Don't

  • Set Electric Blue text on Dark Blue. The contrast fails at every size.
  • Put Beige next to Off White as a text pairing. They read as the same color.
  • Mix Ivy Presto and Instrument Serif in the same headline.
  • Use Ivy Presto or Instrument Serif for body text or tables.
  • Stack the glow, dot grid and gradient text on one slide.
Reference

Tokens for developers.

Paste this into any web project, landing page or Notion embed to start on brand.

:root {
  /* Fine Cut core colors */
  --fc-offwhite:  #F5F5F5;
  --fc-darkblue:  #15273D;
  --fc-electric:  #3250F5;
  --fc-beige:     #FFEEDB;
  --fc-electric-soft: #94A3F5; /* text on dark */

  /* RGB channels for opacity: rgba(var(--fc-electric-rgb), .32) */
  --fc-offwhite-rgb: 245, 245, 245;
  --fc-darkblue-rgb: 21, 39, 61;
  --fc-electric-rgb: 50, 80, 245;
  --fc-beige-rgb:    255, 238, 219;

  /* Opacity steps */
  --o-80: .80; --o-64: .64; --o-48: .48;
  --o-32: .32; --o-16: .16; --o-8: .08;

  /* Fonts */
  --font-sans:    "Inter", system-ui, sans-serif;
  --font-display: "ivypresto-display", "Instrument Serif", Georgia, serif;
  --font-accent:  "Instrument Serif", Georgia, serif;

  /* Tracking */
  --ls-head: -0.04em;   /* Inter headlines */
  --ls-body: -0.02em;   /* Inter body */
  --ls-serif: -0.01em;  /* Ivy + Instrument */
  --ls-caps: 0.12em;    /* eyebrows */

  /* Radius */
  --r-sm: 4px; --r-md: 8px; --r-lg: 16px; --r-pill: 999px;
}
