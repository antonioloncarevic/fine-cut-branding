Foundations

Four colors, clear roles.

Dark Blue carries the brand. Electric Blue pulls the eye. Off White is the light ground. Beige is a text accent on Dark Blue and never a background.

HEX #FFEEDBRGB 255 238 219var(--fc-beige)

Usage ratio per layout

60 / 30 / 7 / 3. Dark Blue dominates, Off White carries light surfaces and text, Electric Blue stays rare so it keeps its punch, and Beige only appears as text. On light-first layouts, swap the first two.

Reference

The rules that keep it consistent.

Do

  • Stick to the five text pairings. Nothing outside that list.
  • Keep Electric Blue to a small share of any layout, so it always reads as the accent.
  • Use one serif accent per headline, one to three words long, in a flat color.
  • Use one gradient line and one glow button per screen at most.
  • Use Ivy Presto only at 40px and above, where its contrast shows.

Don't

  • Use Beige as a background, anywhere. It's a text color on Dark Blue only.
  • Set Electric Blue text on Dark Blue. It disappears at every size.
  • Use Playfair Display for anything other than the Fine Cut wordmark.
  • Put a gradient on the serif accent inside an Inter headline.
  • Stack the glow, dot grid and gradient text on one slide.

:root {
  /* Fine Cut core colors */
  --fc-offwhite:  #F5F5F5;
  --fc-darkblue:  #15273D;
  --fc-electric:  #3250F5;
  --fc-beige:     #FFEEDB;  /* text on Dark Blue only */

  /* RGB channels for opacity: rgba(var(--fc-electric-rgb), .32) */
  --fc-offwhite-rgb: 245, 245, 245;
  --fc-darkblue-rgb: 21, 39, 61;
  --fc-electric-rgb: 50, 80, 245;

  /* Opacity steps */
  --o-80: .80; --o-64: .64; --o-48: .48;
  --o-32: .32; --o-16: .16; --o-8: .08;

  /* Fonts */
  --font-wordmark: "Playfair Display", serif;  /* 500 italic, -0.06em */
  --font-display:  "ivypresto-display", "Instrument Serif", serif;
  --font-sans:     "Inter", system-ui, sans-serif;
  --font-accent:   "Instrument Serif", serif;

  /* Signature gradients */
  --grad-chrome:         linear-gradient(116deg, #FFFFFF 0%, #D8D8D8 23%, #FFFFFF 46%, #BDBDBD 68%, #FFFFFF 100%);
  --grad-beige-chrome:   linear-gradient(116deg, #FFFFFF 0%, #FFEEDB 25%, #FFF9F2 48%, #E9D3BA 70%, #FFEEDB 100%);
  --grad-dusk:           linear-gradient(120deg, #AEBBFF 0%, #F5F5F5 50%, #FFEEDB 100%);
  --grad-electric-shine: linear-gradient(132deg, #1C33C9 0%, #3250F5 30%, #8B9DFF 55%, #3250F5 78%, #15273D 100%);
  --grad-electric-ink:   linear-gradient(135deg, #3250F5 0%, #15273D 100%);

  --ls-head: -0.04em;

  --ls-serif: -0.01em;
  --ls-caps: 0.12em;
